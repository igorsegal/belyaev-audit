## 0. ОПРЕДЕЛЕНИЯ (стр. 166)
- **Прогон** — `Ind[c] - Ind[c-1]` (разница двух последних закрытых свечей).
- **Прогон цены** — `Close[c] - Close[c-1]`. Используется в свечных фигурах.
- **Схождение/расхождение** — несоответствие направления движения цены и индикатора между сопоставляемыми точками.
- **Прорыв** — авторское преобразование схождения/расхождения в схемах2.9/2.10; при преобразовании исходный сигнал отсутствует. Отдельный численный вес не задан (стр.31–32; раздел67).
- **Неправильный прогон** — см. п.16.
- **Фигура** — конфигурация 3 последних прогонов.
- **Тяжёлый график** — следующий старший ТФ (D→W, W→M).
- **Расчётная свеча** — последняя **закрытая** свеча.
## 1. ПРАВИЛО ЭТАЛОНА (стр. 44, 133)
- Направление ненулевого последнего прогона = **эталон, 100 баллов**.
- **U-05 (утверждено пользователем 01.11.2026):** если последний прогон равен нулю (`Ind[c] == Ind[c-1]`), прогноз данного индикатора **неопределённый**: `(P_up, P_down) = (50, 50)`. Предыдущий ненулевой эталон не переносится. Проверка выполняется до правил обработки `S`; U-04 применяется только при существующем ненулевом эталоне.
- `S` — знаковая сумма баллов без эталона (+ вверх, - вниз).
- Если `|S| >= 100` И `sign(S) != sign(эталон)` → **смена эталона**, 100% в сторону `S`.
- **U-03 (утверждено):** если `0 < |S| < 100` И `sign(S) != sign(эталон)`, эталон **сохраняется**. Вероятность **стороны эталона** = `100 - |S|`, противоположной стороны = `|S|`.
  - Эталон вверх, `S = -25` → `P_up = 75`, `P_down = 25`.
  - Эталон вниз, `S = +25` → `P_up = 25`, `P_down = 75`.
  - Это правило сохраняет эталон даже при вероятности его стороны ниже 50%; эталон и сторона большей вероятности — разные понятия.
- Если `sign(S) == sign(эталон)` → эталон **сохраняется**, 100%.
- **U-04 (утверждено пользователем 01.11.2026):** при `S == 0` эталон сохраняется, вероятность стороны эталона — **100%**, противоположной стороны — **0%**. Это относится к отсутствию дополнительных баллов и к их взаимному погашению. Старое исключение «S=0 → 50/50» отменено. Правило применяется при ненулевом последнем прогоне; при нулевом прогоне действует U-05.
## 2. РЕЖИМ РЫНКА (стр. 132)
- `ADX[c] < ADX[c-1]` И `ADX[c] >= 20` → **FLAT (CCI + DM)**.
- `ADX[c] > ADX[c-1]` И `ADX[c] >= 20` → **TREND (EMA + MACD)**.
- `ADX[c] == ADX[c-1]` → **50/50 (неопределенность)**.
- `ADX[c] < 20` → **50/50 (неопределенность)**.
## 3. СЛИЯНИЕ ВЕРОЯТНОСТЕЙ (стр. 45, 145)
Для двух индикаторов (каждый — пара `(P_up, P_down)`):
- `P_up = (P1_up + P2_up) / 2`
- `P_down = (P1_down + P2_down) / 2`
**Конфликт:** если `P_up == 50` И `P_down == 50` → **не торгуем**.
**Пример:** `P1 = (100, 0)`, `P2 = (0, 100)` → `P = (50, 50)` → конфликт, не торгуем.
## 4. СЛИЯНИЕ ВНУТРИ MACD (стр. 45)
- MACD(L) → `(P_up_L, P_down_L)` по п.12.
- MACD(G) → `(P_up_G, P_down_G)` по п.12.
- Слияние: `P_up = (P_up_L + P_up_G) / 2`, `P_down = (P_down_L + P_down_G) / 2`.
- **Конфликт** (50/50) → не торгуем.
**Важно:** «цвет» MACD (знак значения) — это **не** то же самое, что «эталон» (направление прогона). В п.4 используем вероятности из п.12, а не «цвета».

## 6. 44 ФИГУРЫ (стр. 58–67)
**Совместный учёт:** разные применимые свойства суммируются по U-53 с сохранением явно принятых локальных приоритетов, исключений и компенсаций. Универсального выбора по наибольшему номеру нет; F-45/46 дополняют соответствующую вилку по U-10.
**Наклон:** `наклон = (Ind[c] - Ind[c-1]) / |Ind[c-1]|`.
**Соизмеримость:** `|body1 - body2| / max(body1, body2) <= 0.13`.
**«Значительно отличается»:** для неотрицательных сравниваемых величин `|x-y| > 0.382*max(x,y)` (U-06); ожидаемая точка фигур 21–24 пока не определена.
**«Против ожидания» (фигуры 17–18):** быстрая идёт **против направления первой свечи**. Белая + вниз = против. Чёрная + вверх = против.
**Flat (фигуры 27–28):** `|наклон| < 0.13`. При Flat фигуры 29–44 **не срабатывают**.
**«Верхняя граница» (фигуры 1–2):** для Stoch/RSI = 80/20; для CCI = ±100.

## 7. БАЛЛЫ DM (стр. 90–92)
**+DM и -DM — два независимых индикатора.** Считаем каждый по правилу эталона, потом сливаем через `(P_+DM + P_-DM) / 2`. Разное направление двух прогнозов само по себе не означает 50/50: конфликт определяется по итоговой паре согласно п.3.
### U-02 — последовательные проверки DM (исправлено и утверждено 02.11.2026)
- Сначала проверяется правильность направления +DM относительно изменения High и -DM относительно изменения Low на двух последних закрытых свечах.
- Проверка соотношения величин допускается только после подтверждения правильности ОБОИХ направлений. Если хотя бы одно направление неправильное, учитывается применимый штраф направления, а проверка соотношения не выполняется и штраф за соотношение не начисляется.
- Пропуск проверки соотношения означает «неприменимо», а не доказанное правильное соотношение. Неустановленная правильность из-за отсутствующих данных или ещё не определённого случая равенства также не разрешает переход к сравнению отношений.
- Прежнее разрешение независимо начислять штрафы направления и соотношения на одном наборе прогонов отменено. Основание: стр.91, пункт3, и стр.93 перед таблицей4.7 и после неё.
- Само U-02 не задаёт новых величин/направлений штрафов и не заменяет отсутствующие формулы проверок. Основа для восстановления определений — разделы книги 4.10–4.13; см. конечный список нерешённых вопросов.
- Эффективность признаков проверяется исторически после корректной реализации, отдельно от определения нормативов.

## 8. БАЛЛЫ CCI (стр. 132–134)
**CCI(5) = быстрая (Б), CCI(8) = медленная (С).** Каждый индикатор имеет собственный эталон.
**U-01 (утверждено), таблица 7.3:** при `Б = С` вклад быстрой CCI **пропускается**. Это исключение имеет приоритет над прежней общей формулой усреднения. Пропущенный вклад нельзя автоматически подменять парой `(50, 50)` и усреднять с медленной.
Для остальных случаев порядок объединения должен быть восстановлен по таблице 7.3; прежнее `(P_cci5 + P_cci8) / 2` не считается доказанной заменой этой таблицы (см. конечный список нерешённых вопросов).

## 15. ПОРЯДОК АГРЕГАЦИИ ИНДИКАТОРОВ
**Все индикаторы возвращают пару `(P_up, P_down)`.**
**Trend-режим (ADX вверх):**
1. MACD(L) → `(P_up_L, P_down_L)`
2. MACD(G) → `(P_up_G, P_down_G)`
3. MACD: `P_macd = (P_L + P_G) / 2` (по п.4)
4. EMA: `P_ema = (100, 0)` если 5>8>13, `(0, 100)` если 5<8<13, `(50, 50)` иначе
5. Итог: `P_trend = (P_macd + P_ema) / 2`
**Flat-режим (ADX вниз):**
1. CCI(5) → `(P_up_5, P_down_5)`
2. CCI(8) → `(P_up_8, P_down_8)`
3. CCI: объединение по таблице 7.3 и U-01 (п.8); универсальное среднее здесь не утверждено.
4. +DM → `(P_up_pdm, P_down_pdm)`
5. -DM → `(P_up_mdm, P_down_mdm)`
6. DM: `P_dm = (P_pdm + P_mdm) / 2`
7. Итог: `P_flat = (P_cci + P_dm) / 2`
**Финальный прогноз:** `P_up` и `P_down` из `P_trend` или `P_flat`.
## 16. ОПРЕДЕЛЕНИЕ «НЕПРАВИЛЬНОГО ПРОГОНА» (инженерное)

### U-06. Допуски и маленькая свеча — утверждено пользователем
- Это инженерные определения, не дословные правила автора.
- Соизмеримость неотрицательных величин: `abs(x-y) <= 0.13*max(x,y)`. Нулевая пара соответствует равенству без деления.
- Значительно больше/меньше: `abs(x-y) > 0.382*max(x,y)`. Сам знак больше/меньше устанавливается отдельно.
- Приблизительно 100: 87–113 включительно. Авторский пример CCI 86.77 не входит; исключение не расширяет допуск автоматически.
- Тело закрытой свечи `B[t]=abs(Close[t]-Open[t])`.
- Маленькая свеча: `B[t] <= 0.13*(B[t-1]+B[t-2]+B[t-3])/3`. Нужны три предыдущие закрытые свечи; текущая оцениваемая в среднее не входит, тени исключены.
- Для выбора веса неправильного прогона MACD критерий маленького тела заменяет критерий «волчок»: установленное нарушение на маленькой свече получает 25, на остальной — 50. Размер сам по себе нарушения не создаёт.
- Допуск не изменяет направления, пересечения и явно заданные автором отношения «в два и более раза».
- Сравнение силы прогонов выполняется по абсолютным изменениям за бар; знак проверяется отдельно. Прежняя формула относительного наклона п.6/17 не применяется к сравнению ΔA/ΔH. Определение Flat остаётся открытым.

### U-07. MACD — утверждено пользователем
- `A=EMA8(Close)-EMA13(Close)`; `S=EMA21(A)`; `H=A-S`.
- A — быстрая линейной MACD, S — сигнальная (медленная), H — гистограмма. Огибающая H использует те же значения, что столбики.
- Это принятое инженерное исправление формулы стр.33. Способ начальной инициализации EMA данным решением не меняется.
- Для гистограммы положение проверяется относительно нуля: H>0 → 25↑; H<0 → 25↓. Подпись Б<М в примерах гистограммы не используется как дополнительный признак.
- Линейная часть: A>S → 25↑; A<S → 25↓. Отдельный расчёт S не производится.
- Пересечение A/S либо H/0: 25 в направлении пересечения, а не общий осцилляторный вес 50.
- Вторая тень: белый расчётный цвет и отрицательный последний прогон соответствующей части → дополнительно 25↓; чёрный цвет и положительный прогон → дополнительно 25↑.
- При расчёте тени MACD тяжёлый график исключить; остальные применимые свойства сохранить.

### U-08. Соотношение наклонов MACD M-12/13 — утверждено пользователем
- `dA=A[t]-A[t-1]`, `dH=H[t]-H[t-1]`, только закрытые свечи.
- Чёрная свеча: dA>0 и dH>0 и `abs(dH)<=0.5*abs(dA)` → H получает 25↓.
- Белая свеча: dA<0 и dH<0 и `abs(dH)<=0.5*abs(dA)` → H получает 25↑.
- Во всех остальных случаях вклад этого свойства 0, включая нулевые прогоны и O=C.
- M-12 и M-13 — один признак, начислить один раз. Более сильная гистограмма сама по себе не штрафуется этим правилом.

## 22. U-09 — ОЖИДАЕМАЯ ТОЧКА, 01.11.2026
Пользователь предложил линию через значения двух предыдущих баров и разрешил продолжить после уточнения о продлении на один бар. Принято инженерное определение:
`expected[t]=2*I[t-1]-I[t-2]`.
- I[t] — фактическое значение последней закрытой свечи, в построении expected не участвует.
- Оба исходных значения и время их доступности предшествуют оцениваемому бару; будущие бары запрещены.
- Пример:10→14 даёт expected18; это экстраполяция фактического предыдущего прогона, а не доказанное воспроизведение авторского пунктирного пути.
- Нормировка отклонения — инженерный выбор редакции в рамках разрешения формализовать: `step=abs(I[t-1]-I[t-2])`, `error=abs(I[t]-expected[t])`.
- При step>0: error<=0.13*step — близко к ожидаемой; error>0.382*step — значительное отклонение; промежуток(13%,38.2%] — промежуточное отклонение без дополнительного штрафа за значительность.
- При step=0: если error=0 — точное совпадение; иначе NEED_SCALE. Деление на ноль и произвольное использование уровня I как масштаба запрещены.
- Нормировка по длине прогона инвариантна к добавлению постоянного уровня к I; отрицательные значения и переход через ноль не меняют оценку.
- Пороговые сравнения должны выполняться без округления отображаемых чисел.

## 27. U-12 — КАСАНИЕ И ПЕРЕСЕЧЕНИЕ, УТВЕРЖДЕНО 01.11.2026

### Расчёт ожидаемой точки и отклонения
- `expected=2*I[t-1]-I[t-2]` по U-09.
- `step=abs(I[t-1]-I[t-2])`, `diff=I[t]-expected`, `error=abs(diff)`.
- При step>0 применяются следующие взаимоисключающие ветви:
  1. `error<=0.13*step`: вклад связанных неправильных прогонов в ТЕКУЩЕМ расчёте0; компенсирующее правило само дополнительных баллов не даёт.
  2. `error>0.382*step`: связанные неправильные прогоны заменяются ОДНИМ вкладом50 в направлении diff: diff>0→50↑, diff<0→50↓.
  3. `0.13*step<error<=0.382*step`: обычный расчёт нарушений сохраняется без изменения.
- Ровно13% относится к совпадению, ровно38.2% — к промежуточной ветви. Округление до проверки запрещено.
- При step=0 и error=0 — совпадение; при step=0 и error>0 сохраняется NEED_SCALE U-09: не подставлять произвольный знаменатель. Если для первого прогона не установлено направленное нарушение, предварительное условие U-16 уже не выполнено.

### 44.2. Три независимые оси вариантов
**A — порог величины прогона быстрой.**

**B — временная связь событий.**
- SAME_BAR: пересечение быстрой одного из уровней ±100 и подтверждающее событие медленной происходят на одном закрытом баре.
- SAME_RUN: допускаются разные бары в пределах одного прогона быстрой; условие рассматривается после второго события и выполнения порога величины.

**C — подтверждающее событие медленной.**

## 59. U-40 — R-09: нейтральные результаты и недостаток данных, утверждено 02.11.2026

| Ситуация | Итог |
|---|---|

## 60. U-41 — завершение R-09: итог первой тени при полном наборе результатов, утверждено 02.11.2026

Пусть A — число сигналов против прогнозируемого тела, B — число сигналов по телу. Каждый из четырёх инструментов даёт один направленный либо нейтральный результат. При полном наборе рассчитанных результатов:
1. A>=2 → высокая вероятность первой тени. Этот пункт имеет приоритет, в том числе при A=B=2.
2. A<2 и B>=2 → малая первая тень.
3. A<2 и B<2 → неопределённость.

Первый пункт — авторское условие стр.146. Второй и третий — принятая формализация по примеру стр.160, а не дословное общее правило автора. «Малая» не означает отсутствующую, «высокая» не получает произвольной численной вероятности. Неописанные автором сочетания маркировать отдельно для исторического сравнения; принятое правило — базовая трактовка, эффективность не доказана. Исследовательский и контрольный периоды разделять; прогнозировать до начала следующей свечи, без будущих/незакрытых баров. Порядок движения внутри свечи требует более подробной истории, OHLC одного бара недостаточно. Точность прогноза тени и торговую прибыльность оценивать отдельно. Конкретные границы периодов и критерии победителя пока не назначены.

## 65. U-46 — R-14: подтверждение локального экстремума, утверждено 03.11.2026

Основание: электронный текст книги, стр.27–30. Автор описывает локальные вершины/впадины и запрещает промежуточные пересечения соединяющей линии с индикатором. Вычислительное подтверждение обратным прогоном — согласованное уточнение, не дословная формула автора.

- Вершина подтверждается первым закрытым прогоном вниз после роста.
- Впадина подтверждается первым закрытым прогоном вверх после снижения.
- В простом случае двух соседних ненулевых разнонаправленных прогонов экстремум находится на их общем узле: рост до I[t-1], затем снижение до I[t] подтверждают вершину I[t-1]; снижение, затем рост подтверждают впадину I[t-1].
- Время экстремума и время его доступности различаются: точка становится доступна только после закрытия подтверждающего бара t. Использовать её в решениях до этого момента запрещено. Подтверждение не переписывает прошлые расчёты.
- Бар0 и бары с BarCloseTime > CurrentDecisionTime исключаются. Финальные значения будущих баров для подтверждения недоступны.
- Обязательный пятибарный фрактал и произвольный фиксированный максимум расстояния между точками не вводятся. Автор допускает три свечи для свойства; максимальную протяжённость ограничивает отсутствием других пересечений индикатором соединяющей точки линии. Точное определение промежуточного касания ещё не согласовано.
- Серии равных значений, плато, применение допуска FLAT к смене направления и выбор узла при равных экстремумах этим согласием не определены. Нового допуска не вводить; R-14 остаётся частично открытым в этих пределах.
- Выбор пар цены/индикатора и их привязка по времени относятся к R-15. Подтверждение одной точки не означает готовности всего признака дивергенции.
- C++ не изменён; соответствие реализации и историческая эффективность не проверены.

### Местная работа средних — правила главы1

- 1-я средняя — линия Close. Местную работу определяют1-я,5-я и8-я средние (стр.18–19); подмена всей группы одним наклоном EMA5 отменяется.

- Если 1-я средняя вверх пересекла8-ю и5-ю снизу вверх → сильная верхняя местная работа (стр.20).
- После пересечения одной из средних, если1-я осталась между5-й и8-й, автор считает дальнейшую работу неопределённой (случаи1 и5, стр.19–20).
- 1-я вниз осталась выше5-й → малая вероятность нижней работы;1-я вверх осталась ниже8-й → малая вероятность верхней, наиболее вероятна нижняя работа (случаи2 и4, стр.19).
- При первом развороте1-й сравнить расстояние L=abs(EMA5−EMA8) на последней и предпоследней закрытых свечах: L[t]>L[t−1] → сильный сигнал нового направления; L[t]<L[t−1] → слабый сигнал нового направления и вероятнее продолжение прежней тенденции (стр.20–21). Расположение5-й и8-й относительно друг друга в этой проверке не имеет значения.
- Равенство расстояний и одновременное сочетание нескольких авторских свойств не получают придуманного приоритета.
- В месячном примере1-я пересекла5-ю и8-ю вниз, автор получил нижнюю местную работу при белом прогнозе тела (стр.140). Это прямое подтверждение того, что сигнал местной работы не сводится к цвету тела.

## 68. U-48 — R-25: исправленная формула ROC, утверждено 03.11.2026

## 81. U-61 — R-18: допуск касания линии индикатора, утверждено 03.11.2026

- При недостатке истории масштаб недоступен; отсутствие данных не означает касание. Оценивается линия индикатора, не тень свечи цены.

## 82. U-62 — R-18: повторные касания и прекращение линии, 03.11.2026

## 83. U-63 — R-24: неопределённость местной работы средних, утверждено 03.11.2026

Авторская основа — местная работа1-й,5-й и8-й средних, стр.18–21. Автор описывает увеличение/уменьшение расстояния5–8, но не назначает результата равенству и общего приоритета всех сочетаний местной работы. Следующее завершение прямо утверждено пользователем:
